## unDrifted Response 001

**Quotation selections (5):**

1. "AI agents are not entering empty systems. They are entering organizations already composed of fragmented
   procedures, inherited permissions, unclear ownership, informal approvals, disconnected data, overlapping
   tools, and responsibilities that may never have been explicitly defined."
2. "Capability answers: Can the system do this? Governance must answer: Should this function exist, who or
   what may perform it, under which authority, within what boundaries, and with what evidence?"
3. "A perfectly identified agent can still be assigned the wrong objective. A tightly permissioned agent can
   still optimize a harmful process. A monitored agent can still faithfully execute a position that should
   never have been established."
4. "AI outcomes are constrained by the operational environments in which AI participates."
5. "The question is no longer only: How powerful will AI agents become? It is becoming: What kind of
   institution can responsibly receive them? ... it cannot be answered by the model alone."

**Publication excerpts (3):**

1. "An AI agent receives more than a task" (full section).
2. "The environment must be measured first" (full section).
3. The closing three-line field finding / unDrifted position / Measures Registry relevance block.

**Discussion prompts:**

- The article separates "capability" (can the system do this?) from "governance" (should this function exist,
  under what authority?). Which question does your organization actually ask first?
- "Identity is necessary, but it is not enough" — what would it take for your organization to answer the
  second question, not just the first?
- Measures Registry's premise is "measure the environment before assigning autonomous capability within it."
  What would that measurement actually need to cover, concretely, in your own systems?

**Editorial pull quote:**

> "AI is not broken. Systems are." — the closing line of this framing also anchors unDrifted's original launch
> cover story; the Response returns to it from a different angle, applied to autonomous agents specifically.

**Short teaser copy:**

> The problem isn't the agent. It's the position you gave it.

**Publication preview copy:**

> unDrifted Response 001: "AI Agents Are Not Entering Empty Systems." A response to Field Findings 2026-W28,
> arguing that agent security failures are, underneath, environmental governance failures — and that the
> environment has to be measured before autonomous capability is assigned within it.
