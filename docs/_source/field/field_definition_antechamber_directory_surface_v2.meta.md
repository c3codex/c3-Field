# Field Definition — Antechamber Directory Surface

## Purpose

Seat Antechamber in Field as the first directory surface for incomplete signal.

Antechamber does not recognize, convert, or reveal by entry alone.

Antechamber exists to:

- hold incomplete signal
- structure intake relation
- serve as systems communication and control surface
- bind early continuity surfaces
- establish OAR1 readiness
- prepare passage eligibility without granting passage prematurely

## Native Position

Within native order:

- Codex holds authority
- Field structures intake relation
- Measures registers reveal and progression
- Chazz executes only what is already defined

Antechamber belongs to Field as schema-level directory and intake structure.

It is not:

- Codex authority
- Measures registry
- Chazz execution body
- encounter completion
- Legacy seating

## Start Standing

All entry into Antechamber begins incomplete.

Incomplete entry is valid.
Premature passage is not.

Valid starting incompletion may include:

- partial intent
- partial contact state
- partial upload state
- partial Envelope formation
- unresolved intake classification
- correction-held continuation

## Structural Role

Antechamber resolves as:

- directory surface
- intake surface
- threshold surface
- systems communication and control surface
- OAR1 origin surface
- Envelope-binding surface
- envKey-bearing continuity surface
- correction-holding surface
- passage-readiness structuring surface

## Required Relations

Antechamber must structurally relate:

- Temple as prior holding container
- Signal as origin-bearing motion
- SRC standing as intake classification
- Envelope as structured carrier
- envKey as Envelope continuity key
- c3 Key as origin access key
- OAR1 as first-touch intake record
- NotChazz as passage constraint intelligence
- Harrumuk Passage as next threshold surface
- Named Individual or Institution in Service as valid origin

No intake standing is valid in isolation.

## Identity Rule

Identity at Antechamber resolves through:

- c3 Key for origin access continuity
- envKey for Envelope continuity

Epithet is not required at intake.
Slug is never authority.

## Required Field States

Antechamber must be able to express these structural states:

- held
- forming
- incomplete
- ready_for_oar1
- correction_required
- blocked
- ready_for_passage

These are structural intake states.
They do not define reveal order.

## Dependency Rule

Readiness in Antechamber depends on relation to:

- valid origin or valid origin path
- intake classification or classification path
- Envelope presence or Envelope formation path
- envKey presence or envKey formation path
- OAR1 eligibility
- NotChazz validation standing

If required relation is absent, signal remains held, forming, incomplete, correction_required, or blocked.

## OAR1 Relation

OAR1 originates in Antechamber at first verified touch.

OAR1 records:

- Objective
- Action
- Result

OAR1 does not:

- define truth
- seat signal in Codex
- complete passage
- create Legacy

OAR1 establishes intake standing for passage readiness.

OAR2 does not originate here.

## Transition Rule

Only signals that resolve required intake relation may transition:

Antechamber -> Harrumuk Passage

No direct transition is valid from Antechamber to:

- Obsidian Directory
- Obsidian Chamber
- Phase Map
- Codex
- Legacy

## Chamber Relation

Harrumuk Passage resolves threshold crossing into Obsidian Chamber.

Obsidian chamber-local readability resolves through Obsidian Directory.

Phase Map follows chamber-local readability as the relational positioning surface.

No chamber-local readability may render prior to chamber entry.
No Phase Map positioning may occur prior to chamber-local readability.

## Boundary Rule

Antechamber may:

- hold incomplete signal
- preserve correction standing
- structure intake relation
- communicate system standing
- bind Envelope continuity
- establish OAR1 readiness

Antechamber may not:

- pass incomplete signal
- invent missing relation
- bypass NotChazz
- seat Codex truth
- render downstream chamber-local readability

## Correction Rule

When intake relation is incomplete or invalid:

- signal remains structurally held
- OAR-addressable standing is preserved
- correction state is maintained without authority drift
- passage does not occur

Correction returns to the missing relation layer, not to frontend improvisation.

## Validation Rule

Antechamber is valid only when it can structurally express:

- incomplete but valid intake standing
- identity continuity through c3 Key and envKey
- OAR1 origination at first verified touch
- held versus ready_for_passage distinction
- NotChazz-constrained transition eligibility
- single valid next threshold relation through Harrumuk Passage
- directory-level systems communication without registry substitution

## End Standing

Antechamber resolves successfully when signal is either:

- held in valid incomplete standing
- routed into correction without drift
- advanced to Harrumuk Passage through satisfied intake relation

Success does not mean passage always occurs.
Success means Antechamber correctly holds or correctly passes.

## Success Condition

Antechamber is properly seated in Field when it can relate incomplete signal to:

- origin
- intake standing
- Envelope continuity
- envKey continuity
- OAR1 readiness
- passage eligibility

without:

- bypass
- premature execution
- authority drift
- registry substitution
- encounter substitution

Codex holds.
Field structures.
Measures registers.
Chazz executes.
