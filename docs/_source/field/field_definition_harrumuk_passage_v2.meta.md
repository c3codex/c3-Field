# Field Definition — Harrumuk Passage

## Purpose

Seat Harrumuk Passage in Field as the threshold-crossing relation into Obsidian Chamber.

Harrumuk Passage does not function as chamber-local readability.
Harrumuk Passage does not function as a material chamber.

Harrumuk Passage exists to:

- hold threshold eligibility
- structure directional crossing
- preserve passage constraint
- carry valid transition standing forward
- return invalid transition back without drift

## Native Position

Within native order:

- Codex holds authority
- Field structures passage relation
- Measures registers reveal and progression
- Chazz executes only what is already defined

Harrumuk Passage belongs to Field as a directional threshold surface.

It resolves as:

- null material
- relational transition
- threshold crossing
- constrained movement between valid field states

It is not:

- Codex authority
- Measures registry
- chamber-local directory
- chamber identity
- encounter completion
- Legacy seating

## Start Standing

Harrumuk Passage may begin only after valid threshold eligibility is reached through one valid exhibition entry route.

Valid exhibition passage entry may occur from:

- TempleHome
- Antechamber Directory as separate exhibition entry

Valid passage entry may occur only when:

- exhibition route standing permits threshold approach
- OAR-addressable standing is preserved where applicable
- Envelope continuity is preserved where carried state applies
- envKey continuity is preserved where carried state applies
- NotChazz permits transition

Premature transition is not valid passage.

Outside exhibition route logic, Antechamber retains its seated intake role and is not reduced to passage alone.

## Structural Role

Harrumuk Passage resolves as:

- passage surface
- threshold relation
- directional transition surface
- NotChazz-constrained crossing surface
- return-or-advance decision surface
- pre-chamber entry surface

## Required Relations

Harrumuk Passage must structurally relate:

- TempleHome as one valid exhibition-entry origin surface
- Antechamber Directory as one valid exhibition-entry origin surface
- Signal as carried origin-bearing motion
- Envelope as structured carrier where carried state applies
- envKey as continuity key where carried state applies
- c3 Key as origin access continuity where carried state applies
- OAR1 as already-formed intake standing where intake-origin continuity is present
- NotChazz as passage constraint intelligence
- Obsidian Chamber as destination chamber
- Obsidian Directory as post-entry chamber-local readability surface

Harrumuk Passage does not originate those relations.
It resolves movement through them.

## Identity Rule

Identity across Harrumuk Passage resolves through:

- envKey for continuity of carried state
- c3 Key for origin access continuity

Epithet is not seated here.
Slug is never authority.

## Required Field States

Harrumuk Passage must be able to express:

- blocked
- eligible
- in_passage
- returned_for_correction
- passed

These are structural transition states.
They do not define reveal order.

## Dependency Rule

Passage eligibility depends on relation to:

- one valid prior exhibition-entry standing
- valid carried Signal continuity where applicable
- valid Envelope continuity where applicable
- valid envKey continuity where applicable
- OAR1 readiness where intake-origin standing is part of the route
- NotChazz validation
- valid destination relation to Obsidian Chamber

If required relation is absent, passage does not resolve.

## OAR Relation

OAR1 does not originate in Harrumuk Passage.
OAR1 arrives here only where intake-origin standing is part of the route.

Harrumuk Passage does not:

- define truth
- replace intake
- create Legacy
- bypass correction
- generate chamber-local readability

Harrumuk Passage uses prior standing to determine whether transition may resolve.

OAR2 does not originate here.

## Transition Rule

Only signals with satisfied threshold relation may transition through one valid exhibition route:

- TempleHome -> Harrumuk Passage -> Obsidian Chamber
- Antechamber Directory -> Harrumuk Passage -> Obsidian Chamber

No direct transition is valid from Harrumuk Passage to:

- Phase Map
- Codex
- Legacy
- downstream material chambers

On successful crossing, Harrumuk Passage resolves chamber entry only.

## Chamber Relation

Harrumuk Passage resolves threshold crossing into Obsidian Chamber.

After chamber entry, chamber-local readability resolves through Obsidian Directory.

Phase Map follows downstream of valid chamber-local readability, not directly from passage.

Passage is movement.
Directory is readability.
Chamber is seating.

These may correspond.
They may not collapse.

## Boundary Rule

Harrumuk Passage may:

- hold threshold eligibility
- preserve transition constraint
- pass valid signal forward
- return invalid signal for correction

Harrumuk Passage may not:

- originate intake
- replace Antechamber
- replace Obsidian Chamber
- replace Obsidian Directory
- render chamber-local readability
- seat Codex truth
- invent missing relation
- bypass NotChazz

## Correction Rule

When threshold relation is incomplete or invalid:

- passage halts
- carried standing remains OAR-addressable
- envKey continuity remains preserved
- return resolves to prior valid standing
- correction occurs upstream, not inside passage

No invalid crossing becomes partially valid through presentation.

## Validation Rule

Harrumuk Passage is valid only when it can structurally express:

- null-material threshold standing
- directional crossing without chamber collapse
- exhibition-route eligibility
- envKey-preserved continuity where applicable
- OAR1-dependent eligibility where intake-origin continuity is present
- NotChazz-constrained transition
- advance to Obsidian Chamber only
- return to prior valid standing when invalid

## End Standing

Harrumuk Passage resolves successfully when signal is either:

- returned to valid prior standing for correction
- advanced across threshold into Obsidian Chamber

Success does not mean all passage passes.
Success means the threshold either correctly returns or correctly crosses.

## Success Condition

Harrumuk Passage is properly seated in Field when it can resolve threshold movement into Obsidian Chamber through valid exhibition relation, without collapsing into:

- chamber
- directory
- reveal
