# Return Antechamber Manifest

Return Antechamber is the post-passage orientation surface.

It is not SRC1.
It is not forced conversion.

Flow:

sealed node  
→ Harrumuk Passage  
→ Return Antechamber  
→ Connect / Phase Map / Temple

Body text:

Measures of Inanna is the work.

Gates, Epithets, and MEs are its measures.

Each measure was placed with intention.
Each applies its own form of pressure.
Each reveals coherence in its own way.

What you have encountered remains with you.
What remains sealed is not withheld, but held in order.

Recognition opens onto a larger Field.

If you feel the call to continue in alignment, you may Connect.

# SRC1 Manifest

SRC1 is individual Connect receipt and acknowledgment.

SRC1 is not institutional SRC.
SRC1 is not SRC2.

SRC1 records:

- Named Individual
- email
- wallet address when present
- receipt of 21 of Coherence
- acknowledgment of 21 of Coherence
- c3 key standing

Preferred:

wallet connect  
→ wallet-held c3 key

Fallback:

verified email  
→ temporary system-generated c3 key

Completion requires:

- valid contact
- 21 of Coherence received
- acknowledgment recorded
- c3 key state resolved

SRC1 opens only when the visitor chooses Connect.

It must not interrupt exhibition return.
It must not replace Return Antechamber.
