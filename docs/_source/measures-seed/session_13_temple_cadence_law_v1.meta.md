# Session 13 — Temple Cadence Law

## Purpose

Lock the authoritative cadence model for chamberplate continuance across the Temple installation.

## Authority Chain

Phase Calendar  
→ exact phased ritual release  
→ Phase Map  
→ only receiver / router  
→ viewable chamberplate continuance

## Structural Standing

- Phase Calendar is the exact release authority surface.
- The sequence relies on the exactness of phased ritual release from Phase Calendar.
- Phase Map is the only receiver/router of that release into encounter visibility and continuance.
- Measures Registry holds structure only.
- Passages govern movement only.
- Chambers hold encounters only.

## Core Law

The exactness of sequence relies on phased ritual release from Phase Calendar.  
Phase Map is the only receiver/router.

## Chamberplate Continuance Rule

A chamberplate becomes eligible only when its phased ritual release standing is exacted through Phase Calendar and routed by Phase Map.

Encounter history governs skip prevention and re-entry:

- if a chamberplate has already been encountered, re-entry is allowed
- if an earlier valid routed chamberplate is unviewed, it cannot be skipped

## Passage Roles

### Harramuk Passage
- entry / return passage
- Temple / Antechamber side threshold
- returns to Antechamber when no further chamberplate is available due to release standing

### Kumurrah Passage
- inter-chamber passage
- governs forward movement between chambers after valid continuance is routed
- does not determine cadence
- does not determine release
- does not determine routing

## Full Continuance Law

1. Phase Calendar exacts phased ritual release.
2. Phase Map receives and routes the next valid chamberplate.
3. If an earlier valid routed chamberplate is unviewed, it must be encountered first.
4. If a chamberplate has already been encountered, re-entry is allowed.
5. Kumurrah carries movement between chambers.
6. If no further chamberplate is available due to phased release standing, Harramuk returns to Antechamber.

## Distinctions Preserved

- Phase Calendar = exact release authority
- Phase Map = only receiver/router
- Encounter history = skip prevention and re-entry permission
- Kumurrah = inter-chamber transition
- Harramuk = entry / return when no valid next routed plate exists
- Chamber = holder only
- Chamberplate / Encounter = active unit
