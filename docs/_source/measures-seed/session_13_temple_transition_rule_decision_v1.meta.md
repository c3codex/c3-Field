# Session 13 — Transition Rule Decision

## Purpose

Determine whether explicit transition rules are required for Temple progression after cadence law resolution.

## Decision

No transition rules are required for progression by default.

## Reason

Progression already resolves through:

- exact phased ritual release from Phase Calendar
- cadence routing through Phase Map
- encounter history preventing skipping unviewed chamberplates
- Kumurrah for inter-chamber forward movement
- Harramuk for return to Antechamber when no valid next chamberplate is available

This means progression emerges from seated cadence and passage structure rather than from a separate rule table.

## Structural Caution

Adding transition rules prematurely would introduce duplication risk across:

- Phase Calendar
- Phase Map
- encounter history
- passage logic

That would create avoidable ambiguity in routing and progression authority.

## Conditional Exception

Transition rules may be seated later only if live DB verification or encounter behavior reveals a true unresolved enforcement gap not already covered by:

- release standing
- cadence routing
- encounter history
- passage structure

## Final Lock

No transition rules are required for progression at this stage.
