# Gates Seating Plan

## Purpose

Define what is ready to be seated now for the seven gates, what remains provisional, and what must remain held until the phase calendar rebuild is exact.

This doc preserves execution restraint.

## Scope

This doc defines:

- current naming standing
- registry-ready fields
- provisional fields
- first release candidates
- explicit hold conditions

This doc does not define:

- final calendar dates
- encounter surfaces
- chamberplate logic
- transition rules
- agreements and resolutions expansions
- full public copy lock

## Registry-Ready Fields

The following fields are sufficiently seated for gate registry planning:

- gate number
- literal item
- ceremonial title guidance
- registry handle guidance
- constraint correspondence
- provisional standing note
- held or release-candidate standing

## Fields Still Provisional

The following remain unconfirmed or intentionally held:

- final Gate 1 title lock
- Gate 7 literal item
- Gate 7 final ceremonial title
- exact release dates
- exact dependencies beyond phase-calendar relation
- encounter surfaces
- transition logic

## Immediate Seating Rule

Only Gate 1 and Gate 2 may proceed toward registry seating after the phase calendar rebuild is confirmed exact.

The remaining gates must remain held.

## Hold Rule

Do not seat Gates 3 through 7 into release standing until:

- the phase calendar rebuild is exact
- release order is confirmed
- downstream cadence is seated against MEs and Chamber of Epithets timing

## Expansion Note

Two valid future expansions are acknowledged and intentionally held out of this seating plan:

- Gates ↔ Agreements
- Gates ↔ Resolutions

Those routes are not to be seated in this pass.

## Validation Rule

This doc is valid if it preserves all of the following:

- Gate 1 and Gate 2 as first release candidates only
- remaining gates explicitly held
- provisional elements explicitly marked
- phase calendar rebuild required before further seating
- agreements and resolutions expansion routes acknowledged but deferred

## Execution Note

This plan exists to prevent premature seating.

A gate is not ready merely because a name is available.
A gate is ready when naming, cadence, and release standing resolve together.

## Closing

This seating plan keeps the next move bounded.

What is ready may proceed.
What is not ready remains held.
