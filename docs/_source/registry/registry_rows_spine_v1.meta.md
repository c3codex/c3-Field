# Registry Rows Spine

## Purpose

Define the current bounded spine-row family for the rewritten registry source stack.

This doc preserves the row set that structures the current path from arrival through Phase Map.

It exists to keep the spine family distinct from:

- chamber-directory rows
- planted gate rows
- planted epithet rows
- planted ME rows

This doc defines the current spine-family content surface.

It does not define:

- row identity shape in general
- geometry rules in general
- structural validity conditions in general
- chamber-directory content
- planted family content
- downstream Kumurrah seating

## Scope

This spine-family pass is currently bounded from:

- Temple
- Antechamber
- Harrumuk Passage
- Obsidian Chamber
- Phase Map

Kumurrah Passage remains downstream and is not yet seated in this current spine-family source pass.

This doc is row-family specific.
It is not the whole registry stack.

## Distinction Chain

The current spine must preserve the following distinctions without collapse:

- arrival does not equal intake
- intake does not equal passage
- passage does not equal chamber
- chamber does not equal positioning

If those distinctions collapse, the spine-family pass is invalid.

- TempleHome entry

That broader exhibition-access logic is preserved without collapsing access into conversion standing.

## Epigraph Dissolution Note

Generic standalone `epigraph` is dissolved as a spine row in this rewritten pass.

Its earlier systems-communication role is no longer seated here.

That function is now carried through Antechamber in the current rewritten pass.

## Antechamber Note

Antechamber remains:

- intake surface
- OAR1 origin surface
- systems communication / control surface
- passage-readiness surface

It may orient and communicate.
It may not fake valid passage.

This remains aligned with the seated Antechamber definition, where incomplete signal may be held but not prematurely passed.

## Material Note

Material remains row-seated where applicable.

For the current spine-family pass:

- Temple = crystal
- Antechamber = lapis
- Harrumuk Passage = null material
- Obsidian Chamber = obsidian
- Phase Map = null material

Passage and positioning rows remain better seated as directional / relational than as embodied material rows.

## Circuit Note

c1, c2, and c3 remain circuit only.

For the current spine-family pass:

- Temple = c1-facing arrival surface
- Antechamber = c1 intake surface
- Harrumuk Passage = c1 threshold movement
- Obsidian Chamber = c2 bounded chamber context
- Phase Map = c2 release visibility and relational positioning surface

Circuit may relate to chamber and material.
It does not replace them.
