## Purpose

### Concordance

The maintained semantic language of the c3 Field.

---

### 7 Constrints of Concordance

1. **Defined**  
   Each term must have a clear functional definition.

2. **Bound**  
   Each term must resolve to:
   - Axis
   - Circuit
   - or System Role

3. **Linked**  
   Each term must connect to related terms within the system.

4. **Singular**  
   Each term holds one primary meaning.
   No dual definitions.

5. **Non-redundant**  
   No duplicate terms for the same function.

6. **Non-drifting**  
   Terms do not change meaning across contexts.

7. **System-valid**  
   Each term must align with:
   - Codex (authority)
   - Field (structure)
   - Measures (registry)
   - system execution (Chazz / NotChazz)

   Measures Conversion is not proven by what it can do.
It is proven by what must be true for Coherence to be encountered, recognized, and govern.
