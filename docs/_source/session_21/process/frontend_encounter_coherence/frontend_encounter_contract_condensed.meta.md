# Frontend Encounter Contract — Condensed

## Purpose

Preserve the frontend as a faithful encounter surface.

Frontend does not author truth.
Frontend renders what has already been seated.

## Native Order

Codex → Field → Measures → Chazz → encounter surface

- Codex holds truth
- Field structures relation
- Measures registers reveal
- Chazz executes
- frontend expresses only what is seated

## Core Rule

Frontend files do not decide what something is.
They decide only how a seated thing is expressed.

## Condensed Constraints

### 1. No component-owned truth
Frontend may not invent semantics, reveal logic, or substitute meaning.

### 2. Distinct reveal bodies stay distinct
description, legend, label, prompt, action, and counter do not collapse unless Measures seats them as one.

### 3. Read contract surfaces only
Encounter files should read from EncounterResolution or another validated contract surface, not guessed raw structure.

### 4. Fallback is not permission
If data is missing, show absence, loading, or failure.
Do not invent substitute content.

### 5. Native material and surface remain intact
material_family, surface_type, encounter_type, and reveal role must remain distinct.
Do not flatten native surfaces into generic UI abstractions.

### 6. Correct the seam before expanding
If render drift appears, stop and restore distinction before adding features.

### 7. File role stays bounded
A frontend file should hold one encounter responsibility and not exceed role.

## Anti-Drift Reminders

Do not:
- hardcode convenience truth
- merge distinct payload bodies
- improve semantics through UX guesswork
- smooth over missing structure
- translate native system meaning into generic app language

## Success Condition

A frontend file is aligned when it:

- reads a valid contract surface
- preserves native distinction
- invents no truth
- substitutes nothing
- exposes absence honestly
- renders exactly what Measures has seated

## Closing

The frontend is not a second author.

Codex holds.
Field structures.
Measures registers.
Chazz executes.
Frontend renders.
