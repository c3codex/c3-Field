# Session 13 — Chamber of Epithets Seating

## Purpose

Seat the Chamber of Epithets without collapsing it into a specific material and confirm epithet routing under the cadence law.

## Core Distinction

Epithet is an encounter unit.  
The Chamber of Epithets is a holder.

## Chamber Standing

The Chamber of Epithets is a non-material relational chamber.

It:
- holds epithet encounters
- does not resolve to a specific material
- does not introduce independent routing logic
- does not override cadence

## Encounter Standing

Each epithet remains:
- an active encounter
- parented to the Chamber of Epithets
- routable only when cadence resolves it through Phase Map

Material, if present, resolves at the encounter level, not the chamber level.

## Routing Law

Routing is determined by cadence resolved through Phase Map.

Therefore:
- epithet routing is not separate from global cadence
- there is no independent epithet routing logic
- there is no chamber-of-epithets routing authority
- passage does not originate routing

## Final Lock Statement

The Chamber of Epithets does not resolve to a specific material.  
It is a non-material relational chamber that holds epithet encounters.  
Material, if present, resolves at the encounter level, not the chamber level.  
Routing is determined by cadence resolved through Phase Map.
