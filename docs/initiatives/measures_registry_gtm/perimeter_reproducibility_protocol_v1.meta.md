# Purpose

Test whether independent reviewers can identify substantially the same consequential relationship perimeter for the same institutional act.

# Reviewer packet

Each reviewer receives the same bounded source packet and no prior perimeter map.

# Reviewer task

For every identified relationship, record:
- actor_a
- actor_b
- relationship purpose
- authority source
- evidence/data passed
- environment/domain
- whether it can materially change the consequential act
- whether it crosses an authority domain
- whether it enters the inner perimeter
- basis for inclusion/exclusion
- uncertainty

# Inclusion rule

A relationship enters the inner perimeter when credible evidence shows it can materially alter one or more of:
- authority
- evidence
- standing
- access
- execution
- return
- consequence

# Exclusion rule

A dependency remains outside the perimeter when it is merely infrastructural or incidental and there is no evidence that variation in that dependency can materially alter the governed act within the observed case.

# Frontier rule

If a previously latent dependency becomes capable of materially altering the act, record the transition as a frontier crossing and update the perimeter without rewriting the prior state.

# Agreement measures

Record:
- total relationships identified by each reviewer
- shared included edges
- shared excluded edges
- disputed edges
- authority-crossing agreement
- perimeter membership agreement
- reason-code agreement

# Minimum reproducibility test

The method fails this round if reviewers disagree on the central consequential edges or if inclusion/exclusion cannot be resolved by source-backed criteria.

The method remains viable if disagreement is concentrated in edge cases while the core consequential perimeter remains stable.

# Conflict handling

Do not average away disagreement.
Record disputed edges as disputed and preserve each reviewer rationale.

# Standing

Research only. This protocol does not establish MAP as a registered method or create Registry standing.
