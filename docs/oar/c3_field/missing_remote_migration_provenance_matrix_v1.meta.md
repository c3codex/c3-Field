## Origin Pattern

Evidence supports a mixed origin pattern:

- migration timestamps renamed or represented differently after remote application: 20260702125802 and 20260709190108 have exact SQL matches under different local/GitHub timestamps.
- direct production execution outside the tracked migration workflow: several rows are present only in the live ledger with exact SQL and no local migration file.
- locally documented but not migration-chain-clean workflows: OAR1 evidence includes dashboard SQL editor, Supabase MCP, and apply_migration/direct execution language.
- current repository does not contain timestamp-matching files for any of the 18 remote-only versions.

No evidence supports using `supabase migration repair` as provenance recovery.
