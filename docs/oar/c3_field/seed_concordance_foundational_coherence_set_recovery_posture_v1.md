# Seed Concordance Foundational Coherence Set Recovery Posture v1

Source OAR2: `docs/oar/c3_field/oar2_seed_concordance_foundational_coherence_set_seating_v1.meta.md`

This recovery posture is non-destructive.

If foundational coherence set seating fails before rows are inserted, stop and route a correction OAR2.

If terms are inserted but relation seating fails, do not delete inserted terms. Mark affected expansion terms `blocked` only under a separate correction OAR2 and preserve trace in metadata.

If relation rows are inserted incorrectly, do not update or delete relation rows through improvised rollback. The authority schema append-protects relation mutation. Route a correction OAR2 that seats a superseding relation or records a blocked correction path.

The 21 of Coherence must not replace protected Chazz execution constraints.

Coherence set semantics may not be inferred during recovery. Seat only what Seed Concordance or The 21 of Coherence explicitly defines.
