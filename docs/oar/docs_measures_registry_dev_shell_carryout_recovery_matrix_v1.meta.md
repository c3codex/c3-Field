# Measures Registry Dev Shell Carryout Recovery Matrix v1

## Classification Rule

A carryout is a preserved artifact, contract, readback, audit finding, closeout, or current source binding that may inform later dev-shell isolation. Carryout existence does not establish launch, public, integration, payment, MAP, SEAT, publication, or social authority.

Broad Batch 1 classification is context only. Protected other-system material remains protected. This audit does not populate working directories or consolidate artifacts into a new authority surface.
