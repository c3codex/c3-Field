# OAR2 — Correct Launch-Grade Visual System, Chamber Differentiation, and Responsive Encounter Design v1

## OBSERVED

The prior runtime correction successfully added material and layout markers across public roots, but it did not visually transform the site.

The OAR1 confirms the correction normalized `data-material-family` and `data-layout-contract` markers, passed build validation, and did not deploy or mutate DB. It also confirms browser visual QA was not completed because browser automation was unavailable.

Live operator review confirms the rendered site still fails the launch-grade visual standard:

1. Crystal Chamber looks weak and visually unprofessional.
2. Material chambers are not visually distinct enough.
3. Backgrounds, borders, and containers feel too similar across materials.
4. Containers do not complement each other or form a mature institutional design system.
5. Structural Drift publication cover is cut off inside the publication container.
6. AI Operations Assessment is partially off-screen on laptop viewport.
7. Branding does not yet feel professional or institution-ready.
8. Assessment does not yet feel like a branded, copyrighted Measures Registry encounter.
9. Media quality is high, but the surrounding interface does not match it.
10. The site does not yet visually communicate “AI-accelerated institutional system.”

This OAR2 authorizes visual/runtime correction.

This is not another marker-only OAR.

## ALIGNED

The rendered public site must visually express the material contracts.

Current markers must become visible composition.

Required standard:

    The site must look governed, institutional, and AI-accelerated before the visitor reads the copy.

Material chambers must be visually distinct:

    Crystal
    = luminous, precise, ordered, high-clarity orientation

    Obsidian
    = dark, operational, threshold-like, controlled assessment

    Lapis
    = deep relational positioning / transition support

    Marble
    = formal, held, governance/inscription tone without public-open implication

The design may use generative-AI-derived visual language if implemented as governed assets, textures, overlays, or registered visual treatments.

Generative styling must not become frontend-owned truth.

If new visual assets are needed, Cody must report required asset roles for operator generation/mapping rather than inventing authority.

`crystal_chamber` must be redesigned into a launch-grade orientation chamber.

Required:

    - professional institutional composition

    - Foundational Leadership CTA and Assess CTA visible or immediately reachable
    - no raw card-stack feel
    - no generic container styling
    - no excessive blankness
    - no cluttered glow/HUD/sci-fi noise

The chamber should feel like:

    precise
    high-value
    AI-accelerated
    institutional
    governed

It should not feel like:

    plain React cards
    generic landing page section
    unfinished dev shell
    raw text grid

## 2. Differentiate material chamber backgrounds

Cody must make chamber materials visually distinct.

### Crystal

    background:
      luminous crystal field / subtle geometry / clean refraction

    containers:
      glass-like but restrained
      crisp edges
      high clarity

    accents:
      subtle cyan/white/gold only where already aligned
      no excessive glow

### Obsidian

    background:
      dark graphite / obsidian threshold
      controlled texture
      deeper contrast than crystal

    containers:
      dark institutional panels
      clear answer affordances
      restrained bevels

    accents:
      minimal cyan/gold/white
      operational, not decorative

### Lapis

    background:
      deep blue relational field
      transition/positioning identity

    containers:
      calmer, softer, relational
      not inherited by assessment

    use:
      only where Lapis is seated

### Marble

    background:
      formal, stone/inscription influenced
      held/governance tone

    standing:
      do not imply Marble is open
      do not create commerce/governance activation
