# OAR2 — Derive Measures Registry Runtime Visual System from Existing Launch Media v1

## OBSERVED

Recent visual correction added a launch-grade CSS layer, but operator review confirms the runtime still does not visually match the quality of the existing Measures Registry media.

The existing launch media already carries the strongest visual system:

- cinematic split-frame composition
- dark institutional blue / graphite field
- crystal and obsidian material contrast
- centered glyph authority
- restrained glow
- clean CTA bands
- large confident copy
- strong environmental depth
- institutional AI infrastructure tone

The runtime pages currently fail because styling is being added around the media instead of being derived from the media.

The correct source reference is already present in the Measures Registry media.

This OAR2 seats that media as the visual source contract for runtime styling.

This OAR2 does not authorize broad visual invention.

## ALIGNED

The existing launch media becomes the visual source reference for Measures Registry public runtime.

Required rule:

    Do not invent a new style.
    Extract the style already present in the launch media and apply it consistently across runtime surfaces.

The site must visually read as:

    institutional cinematic
    dark luxury technical
    governed AI infrastructure
    assessment-grade
    high-trust
    precise

The site must not read as:

    generic SaaS template
    raw React cards
    sci-fi clutter
    mystical clutter
    unfinished proof of concept
    plain text wrapper around good media

The runtime should inherit from the media language:

    background depth
    chamber field
    glyph authority
    ruled CTA bands
    typography confidence
    material contrast
    controlled glow
    cinematic framing

## 2. Runtime design inheritance rule

Runtime styling must be derived from the media language.

Required:

    background fields derive from media tone
    panels derive from media spatial planes
    CTA treatment derives from ruled media CTA bands
    typography scale derives from large confident media copy
    brand mark placement derives from clean media authority
    containers derive from cinematic zones, not generic cards

Blocked:

    generic card-stack styling
    default border boxes
    arbitrary gradients unrelated to source media
    mismatched panel radius
    excessive glow
    random circuit/HUD overlays
    new visual direction disconnected from media
