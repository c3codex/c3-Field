# Measures Registry — Epigraph Contract v1

## Contract Purpose

The Epigraph is the opening encounter of the Measures Registry isomorphic installation.

It establishes tone, orientation signal, and material presence before the visitor reaches the Temple path choice.

The Epigraph does not intake, diagnose, or commerce.

It opens.

## Runtime Anchor

| Field | Value |
|---|---|
| DB encounter_key | `landing_root` / `ai_isnt_broken_intro` (aliased in runtime) |
| Surface state | `intro` |
| Entry registry key | `epigraph` (Measures of Inanna isomorphic pattern) |
| History source | `measures_registry` |
| Media role | `epigraph_video` (primary), `hero_video` (fallback), `hero_image` (still fallback) |

## Material Assignment

The Epigraph carries no single material assignment.

It is pre-material — present before the visitor enters a material-bound chamber.

If a material token is needed for styling continuity, use the base token surface (`measures_registry` design token registry key).

## Opening Signal

The Epigraph must orient the visitor to:

- The nature of Measures Registry as a rendered installation
- The c3 Field system it belongs to
- The governing posture: AI reflects the structure of the environment it operates within
- The path ahead: two paths available at the Temple

## Tone Contract

| Property | Value |
|---|---|
| Voice | Institutional, measured, not promotional |
| Urgency | Contained — present, not pressured |
| Context | Drift and structure as observable forces |
| Signal | The environment is the variable |

## What the Epigraph Must Not Do

- Intake visitor information
- Diagnose AI readiness
- Present pricing or commerce
- Claim assessment authority
- Branch into chamber paths (that is the Temple's role)

## Continuation

From the Epigraph, the visitor proceeds to the Temple.

The Temple carries the path choice. The Epigraph does not route — it orients.

## Boundary

This contract governs tone, presence, and orientation only.

Runtime implementation of the Epigraph is a separate OAR2.

No media, CSS, or DB mutation is authorized by this contract.

## Close

The Epigraph opens the installation.

It does not own the installation.
