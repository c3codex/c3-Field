# Measures Registry — Second Layer Geometry Contract v1

## Contract Purpose

The Second Layer Geometry Contract defines how the first-layer chamber-held material places relate, sequence, mirror, route, return, and resolve within the Measures Registry installation.

First layer seated the places. Second layer governs relation between places.

Only governed relations may become routes.

## First Layer vs Second Layer

### First Layer (Seated)

The first layer established the architecture of the installation:

| Layer Component | Definition |
|---|---|
| Chamber | The bounded authority unit that holds a material place |
| Material Place | The functional position within the installation — carries material identity |
| Contract | The governance document that defines what a place may and may not do |
| Surface | The rendered encounter a visitor experiences at a material place |
| Route / Delivery | The forward movement from one surface to the next |

First layer contracts seated 9 chamber-bound artifacts (OAR1 — Governed Measures Registry Isomorphic Architecture Contract Seating v1).

### Second Layer

The second layer defines how material places relate to one another.

Second layer governs:

- adjacency — what may sit beside what
- dependency — what must resolve before a place may open
- passage — how movement occurs between places
- mirror / isomorphic relation — how Measures Registry mirrors Measures of Inanna
- return — where unresolved signal goes
- conversion — where assessed material becomes qualified asset standing
- boundary — what cannot cross without a future OAR2

Only governed relations may become routes.

Ungoverned adjacency is not permitted.

## Architecture Chain

```
Chamber
  → Material Place
  → Contract
  → Surface
  → Route / Delivery
```

The chain is singular. Collapsing any layer is an architecture violation.

- Chamber ≠ Material Place
- Material Place ≠ Contract
- Contract ≠ Surface
- Surface ≠ Route

## Geometry Functions

### 1. Adjacency

Defines which material places may sit beside one another within the same path.

Adjacency does not imply forced sequence. Adjacent places share relational context.

Ungoverned adjacency is not permitted. A place may not sit beside another place unless their relation is defined in the Place Relation Contract.

### 2. Dependency

Defines what must resolve before a place may open.

Dependency is sequential. A dependent place cannot open until its dependency is satisfied.

No shortcut routing past a dependency is permitted.

### 3. Passage

Defines how movement occurs between places.

Passage is the governed route from one material place to the next. Passage cannot skip dependencies.

Passage must be defined in the Place Route Contract before any runtime implementation may follow.

### 4. Mirror / Isomorphic Relation

Defines how Measures Registry mirrors Measures of Inanna without copying content.

Isomorphic = same architectural shape, different material content.

Pattern: Epigraph opens. Temple branches. Passages carry relation. Material chambers govern function. Measures registers standing. Codex holds authority.

The isomorphic relation is preserved at the architectural level. Content and material function differ.

### 5. Return

Defines where unresolved signal goes.

Return routes handle incomplete qualification, failed intake, or visitor disorientation.

Return must not route to a more advanced place. It routes back to the appropriate relational surface.

### 6. Conversion

Defines where assessed material becomes qualified asset standing.

Conversion is governed. It does not occur spontaneously.

Pattern: c3 MAP qualifies → Obsidian exposes → Marble receives qualified assets → C1/C2/C3 require delivery contract.

### 7. Boundary

Defines what cannot cross without a future OAR2.

Boundary is enforced. No implementation may cross a boundary without a seated contract and a routed OAR2.
