The object should still read unmistakably as a key, with a circular portal-like head, a single vertical access spine, and simplified c3-shaped teeth at the lower end.

The key should feel like a wallet-bound access instrument, not a logo badge.

Style direction:

- dark obsidian metal
- graphite bevels
- subtle cyan-blue circuit lines
- restrained inner glow
- high-precision carved geometry

Around it, include faint concentric field lines or thin gold / cyan orbital geometry, very subtle and elegant.

The stem should include minimal circuit traces that suggest controlled access, registry logic, and one-per-wallet identity.

The lower teeth should imply the number 3 / c3 structure through geometry, but should not look cartoonish.

Material tone:

- obsidian
- graphite
- cyan signal
- faint gold field lines

Background:

- clean marble or light stone surface
- softly lit
- high-end institutional object photography
- realistic shadows
- premium artifact presentation

Composition:

- NFT metadata readable
