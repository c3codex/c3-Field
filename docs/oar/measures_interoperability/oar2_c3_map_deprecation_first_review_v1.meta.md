# OAR2 — c3 MAP / Deprecation-First Review v1

## OBSERVED

Measures Interoperability Session 2 requires a c3 MAP review before deprecation, Codex seating, runtime alignment, or CSS alignment.

The prior working term "golden audit" is replaced by:

**c3 MAP — Measures Alignment Protocol**

c3 MAP diagnoses observed standing and produces a **Measures Resolution Map**.

## ALIGNED

c3 MAP does not define authority.

It maps observed conditions into Measures resolutions and preserves Codex seating process.

Native order remains:

**Codex → Field → Measures → OAR2 → Chazz → Cody-compatible Executor → `src`**

Claude may review under role contract.

Claude may execute only if routed as Cody-compatible executor by approved OAR2.

## ROUTED

Claude is routed to perform review only.

Claude must:

1. Review source standing.
2. Identify candidate drift classes.
3. Identify evidence needed before deprecation.
4. Identify deprecation targets to inspect.
5. Return a Measures Resolution Map.
6. State whether the system is ready or not ready for deprecation execution OAR2.

Claude must not:

1. Modify files.
2. Modify runtime.
3. Modify CSS.
4. Modify database state.
5. Seat Codex authority.
6. Execute from thread instruction.

## RESOLUTION CLASSES

Use only these classes where relevant:

- source_resolution
- schema_resolution
- registry_resolution
- runtime_resolution
- css_resolution
- contract_resolution
- deprecation_resolution
- evidence_resolution
- codex_seating_resolution

## VALIDATION RETURN

Claude must return:

1. Observed sources checked.
2. Drift classes found.
3. Evidence gaps.
4. Deprecation targets to inspect.
5. Required validation outputs.
6. Readiness standing for deprecation execution OAR2.

## BOUNDARY

No runtime or CSS alignment yet.

No Codex seating yet.

No deprecation execution yet.

## SUCCESS CONDITION
