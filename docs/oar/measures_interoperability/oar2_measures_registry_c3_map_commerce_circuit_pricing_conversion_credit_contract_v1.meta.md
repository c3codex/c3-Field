# OAR2 — Measures Registry c3 MAP Commerce Circuit Pricing + Conversion Credit Contract v1

## OBSERVED

The c3 MAP Commerce Circuit + Scope Contract is seated.

It confirms:

| Assessment Standing | c3 MAP Commerce Circuit |
|---|---|
| Coherence Maintained | C1 — Registration Circuit |
| Emerging Drift | C1 — Registration Circuit |
| Structural Drift Detected | C2 — Governance Circuit |
| Critical Drift Exposure | C3 — Delivery Circuit |

It also confirms:

Payment opens the circuit.

Payment does not complete it.

Conversion review completes the circuit.

The Assessment Response Email Contract is seated.

It may deliver assessment standing, observed findings, c3 MAP Commerce Circuit determination, recommended next step, and boundary disclaimer.

It may not claim recognition, verification, certification, payment standing, seal activation, delivery contract standing, or conversion.

This OAR2 defines the pricing and conversion credit rules for the paid c3 MAP Assessment and the corresponding implementation / conversion contract.

## ALIGNED

This contract governs commerce circuit pricing only.

It does not authorize:

- payment activation
- payment processing
- checkout runtime
- invoice generation
- email sending
- seal activation
- delivery contract activation
- conversion claim
- Measures Registry recognition
- runtime modification
- CSS modification
- DB mutation unless separately routed

## CORE RULE

The c3 MAP Assessment price opens the Commerce Circuit and produces institutional MAP assets.

If the institution proceeds into the corresponding governed implementation or conversion contract, the paid c3 MAP Assessment amount is credited toward that contract.

Payment opens the circuit.

Assessment produces the MAP.

Implementation contract authorizes execution.

Conversion review completes the circuit.

## ROUTED

Define three circuit price layers:

1. c3 MAP Assessment price
2. Implementation / Conversion contract floor
3. Assessment credit toward that contract

## CREDIT CONDITIONS

Assessment credit applies only when:

1. c3 MAP Assessment payment is confirmed
2. c3 MAP Assessment is completed
3. institution proceeds into the corresponding governed implementation / conversion contract
4. contract is accepted and executed within the allowed term
5. same institution / assessment key / account relation is bound
6. credit is logged in the commerce trace

## CREDIT DOES NOT MEAN

Assessment credit does not mean:

- refund
- automatic discount without contract
- automatic conversion
- automatic implementation start
- automatic recognition
- verified assessment seal activation
- delivery contract activation
- payment completion for a later contract

## IMPLEMENTATION / CONVERSION BOUNDARY

The c3 MAP Assessment determines the implementation or conversion scope.

It does not authorize implementation.

Implementation begins only through a separate governed implementation / conversion contract.

Assessment maps.

Contract authorizes.

Execution implements.

Conversion review completes.

## OPTIONAL ENTERPRISE / FOUNDATIONAL CONTRACT

The following is not part of default c3 MAP pricing:

Foundational Conversion Cohort / Enterprise Delivery Contract — starting at $250,000+

This may be routed separately after c3 MAP where scope requires enterprise-level conversion, cohort participation, multi-system delivery, or dedicated implementation support.
