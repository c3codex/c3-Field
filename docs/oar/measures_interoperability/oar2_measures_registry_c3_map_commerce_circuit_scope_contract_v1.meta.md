# OAR2 — Measures Registry c3 MAP Commerce Circuit + Scope Contract v1

## OBSERVED

The live Measures Registry assessment encounter is:

- `registry_key`: `measures_assessment`
- `display_title`: `Measures AI Operational Evaluation`
- `encounter_key`: `measures_assessment`
- `material_family`: `obsidian`
- `renderer`: `measures_registry_evaluation_chamber`

This encounter already carries seated assessment mechanics, assessment completion copy, and assessment interpretation logic.

The current assessment is the Obsidian entry surface.

It does not complete c3 MAP.

It determines the appropriate c3 MAP Commerce Circuit for entry into the full Measures Assessment Protocol.

## ALIGNED

This OAR2 defines the relationship between:

1. Measures AI Operational Evaluation
2. c3 MAP Commerce Circuit
3. Payment / Entry
4. Full c3 MAP Assessment
5. MAP Assets
6. System Scope
7. Conversion Review
8. Circuit Closeout

This OAR2 does not authorize:

- payment activation
- runtime modification
- CSS modification
- seal activation
- badge activation
- delivery contract activation
- Measures Registry recognition
- verified assessment standing
- conversion completion
- email sending
- DB mutation unless separately routed

## CORE RULE

The Obsidian assessment determines the circuit.

Payment opens the circuit.

The full c3 MAP produces assets and system scope.

Conversion review completes the circuit.

C1, C2, and C3 are c3 MAP Commerce Circuits.

They are not:

- readiness phases
- certification levels
- recognition levels
- conversion status
- seal standing
- payment completion by themselves

## C1 — c3 MAP Registration Circuit

### Entry condition

- Coherence Maintained
- Emerging Drift

### Function

C1 is the baseline commerce circuit for entering the full c3 MAP where the initial Obsidian reading indicates lower drift pressure or early governance ambiguity.

### MAP assets

- assessment response
- baseline MAP reading
- current-state summary
- governance registration checklist
- recommended documentation route
- light system scope statement

### System scope

- document what exists
- register current governance surfaces
- identify minimum review pathway
- preserve current coherence before expansion
- define next governance maintenance steps

### Completion condition

C1 is complete only when the full c3 MAP assessment resolves through conversion review and the C1 closeout is logged.

## C2 — c3 MAP Governance Circuit

### Entry condition

- Structural Drift Detected

### Function

C2 is the commerce circuit for entering the full c3 MAP where the Obsidian reading indicates governance fragmentation, trace gaps, review-path instability, or structural drift requiring correction.

### MAP assets

- all C1 assets
- structural drift map
- governance gap register
- role / review pathway recommendations
- system trace and dependency notes
- correction priority map
- implementation readiness notes

### System scope

- correct active governance gaps
- define review pathways
- bind operational roles
- stabilize system trace
- identify runtime/source dependency exposure
- prepare system for governed acceleration

### Completion condition

C2 is complete only when the full c3 MAP assessment resolves through conversion review and the C2 closeout is logged.

## C3 — c3 MAP Delivery Circuit

### Entry condition

- Critical Drift Exposure

### Function

C3 is the commerce circuit for entering the full c3 MAP where the Obsidian reading indicates high drift pressure, significant operational exposure, or likely need for deeper conversion / delivery contract review.

### MAP assets

- all C1 assets
- all C2 assets
- conversion scope brief
- delivery contract readiness review
- system dependency map
- runtime/source alignment review
- implementation pathway
- high-touch correction and conversion recommendations

### System scope

- conversion-level review
- dependency and runtime correction
- delivery contract pathway
- system restructuring where needed
- governed implementation support
- conversion readiness determination

### Completion condition

C3 is complete only when the full c3 MAP assessment resolves through conversion review and the C3 closeout is logged.
