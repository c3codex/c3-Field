# OAR2 — Measures Registry Material Styling Contract Seating v1

## OBSERVED

Measures Registry chamber tone and material tonal bed contracts are seated and committed.

The prior OAR1 confirms both tone artifacts were produced and seated, with no runtime, CSS, audio, media, or DB mutation.

The same OAR1 confirms the global tone register:

- institutional
- calm
- precise
- trust-bearing
- audit-grade
- museum-grade
- quietly geometric
- non-hype
- non-fantasy
- non-fear-selling

Lock phrase:

Quiet authority. Visible structure. Governed passage.

Material styling must now be seated as a contract layer before CSS implementation.

## ALIGNED

This OAR2 routes material styling contract seating only.

No CSS file modification.
No runtime implementation.
No DB mutation.
No media upload.
No audio implementation.
No frontend-owned truth.

This contract defines what each material place may look like, but does not implement the styling.

## MATERIAL STYLING RULE

Material styling expresses chamber state.

It does not author authority.

It does not compensate for missing registry state.

It does not create passage, recognition, payment, or conversion.

Measures Registry visual style must remain:

- institutional
