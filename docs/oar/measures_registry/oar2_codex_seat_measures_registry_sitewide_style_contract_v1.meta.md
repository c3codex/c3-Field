# OAR2 — Codex Seat Measures Registry Sitewide Style Contract

## OBSERVED

The runtime audit and seated implementation intelligence confirmed:

- the evaluation chamber is the only fully contracted surface
- typography authority is fragmented
- button behavior is surface-local
- branding mark behavior lacks sitewide governance
- media behavior is inconsistent
- marble tone playback is globally persistent without encounter scoping
- footer/copyright is hardcoded
- viewport fit contracts are incomplete
- transition contracts are unrealized
- encounter containment rules are only partially governed

The runtime itself is structurally reusable.

The missing layer is a seated sitewide runtime/style contract.

## ALIGNED

This OAR2 routes actual Codex seating.

Document creation alone does not constitute seating.

No DB row = not seated.

No validation query = not proven.

The sitewide style contract becomes the governing authority layer beneath encounter contracts and renderer behavior.

Implementation order remains:

    sitewide_runtime_contract
        ↓
    encounter_contracts
        ↓
    renderer_behavior
        ↓
    runtime_state

Identify the correct DB authority surface for sitewide runtime/style governance.

Preferred behavior:

- reuse existing Codex authority structures if valid
- avoid invention of parallel governance surfaces
- if new authority surface required, document justification before insertion
