# OAR2 — Correct Public Threshold Material Identity and Crystal Seat Encounter

## OBSERVED

Runtime audit confirms the public routing is substantially functioning.

However, the public encounter identity has drifted.

The threshold is not simply two navigation paths.

The threshold represents two distinct material encounters.

Current implementation has begun treating the right threshold as an About page or publication path rather than the Crystal Seat Encounter.

This OAR2 corrects that structural drift.
