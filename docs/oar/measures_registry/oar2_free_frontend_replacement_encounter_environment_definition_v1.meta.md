# OAR2 — FREE Frontend Replacement Encounter Environment Definition

## OBSERVED

The former frontend runtime relied on inferred intention.

That model is deprecated.

Frontend no longer acts as runtime authority.

Frontend now resolves through explicit encounter environment components.

The complete replacement architecture now exists:

- registryResolver
- encounterProfileLoader
- encounterComposition
- releaseGate
- EncounterEntry
- EncounterBoundary
- ChamberRouter
- CrystalSeatRenderer
- ObsidianChamberRenderer
- LapisChamberRenderer
- MarbleChamberRenderer
- Optics / EncounterResolution

This architecture requires a supporting definition document.

## ALIGNED

FREE means:

Frontend Replacement Encounter Environment

FREE replaces inferred runtime.

FREE defines the frontend architecture that receives registry-resolved state, passes through the encounter boundary, and manifests only what has already become encounterable.

Native order:

Codex holds.
Systems align.
Measures determine.
Field arranges.
Encounter Boundary allows.
Renderer manifests.
Optics prove.

The who is invariant.

The system does not choose who encounters.

The system chooses what is encountered.

## DOCUMENT PURPOSE

The FREE document must establish:

- runtime is retired as an inferred authority layer
- frontend does not author truth
- frontend does not infer intention
- frontend does not determine standing
- frontend does not arrange Field
- frontend manifests encounterable state only
- missing state remains missing
- unavailable state is public-safe
- renderers receive only released encounter state
- Encounter Boundary is the only transition from prepared state to encounterable state
- Optics observe resolution after manifestation
