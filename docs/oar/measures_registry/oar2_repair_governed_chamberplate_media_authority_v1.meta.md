## ROUTED

### 1. Inspect governed chamberplate standing

For each chamberplate surface in scope, Cody must inspect:

- registry row
- encounter_def
- renderer
- release/access standing
- governed media rows
- fallback media rows
- selected primary media
- runtime retrieval behavior

### 2. Validate source object standing

For each intended governed media object, Cody must verify:

- provider
- bucket
- storage path
- retrieval status
- content type
- active status

Only verified source objects may become governed authority.

### 3. Repair governed mappings where required

Cody may:

- create governed media asset rows
- update governed media mappings
- correct role assignment
- correct sequence precedence
- correct video/still priority ordering

Only when:
- source object is verified
- retrieval returns 200
- mapping remains deterministic

### 4. Chamberplate precedence rule

For chamberplate surfaces:

- governed video must take precedence when active and retrievable
- governed still acts as fallback support only
- failed video retrieval must fall through correctly to still media
- fallback rows may supplement but not override governed rows

### 5. Validate runtime render

For each repaired chamberplate surface, Cody must validate:

- registry resolution
- encounter resolution
- renderer support
- primary media selection
- media retrieval status
- final render result

### 6. Boundary

No held-source decisions.

No fallback deletion.

No bucket deletion.

No hardcoded media URLs.

No unrelated surface mutation.
