Measures Registry launch repair has reached profile-standing seam.

Current standing:

- site architecture resolves
- FREE is active route authority
- registered_runtime is retired / rollback-only

## PROFILE RULE

Profiles must be declared by DB / registry standing before becoming active presentation identity.

A renderer may apply a profile only when the active encounter, chamber, surface, material, media, CTA, density, footer, or reading/legal context resolves that profile from seated registry state or existing supported metadata.

Profiles classify presentation behavior.

Profiles do not create content, meaning, authority, access, payment, score, report result, release state, route authority, or certification.

If a profile is missing:

- FREE may render safe fallback mechanics
- FREE may not invent profile meaning
- FREE may not silently assign chamber identity
- FREE may not mutate report copy, scoring, payment, or route standing
