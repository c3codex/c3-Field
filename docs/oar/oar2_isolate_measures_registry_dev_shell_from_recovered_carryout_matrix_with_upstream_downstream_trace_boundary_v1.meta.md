# OAR2 — Isolate Measures Registry Dev Shell from Recovered Carryout Matrix with Upstream Downstream Trace Boundary v1

## OBJECTIVE

Isolate the Measures Registry dev shell from the recovered carryout matrix.

This OAR2 must separate:

- current dev shell
- dev shell candidates
- protected upstream trace
- downstream held authority
- deprecated terms and residue
- backoffice-held material
- operator-review conflicts

This OAR2 must look both upstream and downstream to ensure trace is isolated and does not bleed into the active dev shell.

No files may be moved, deleted, rewritten, or mutated.

No working directories may be populated.

No authority may be created.
