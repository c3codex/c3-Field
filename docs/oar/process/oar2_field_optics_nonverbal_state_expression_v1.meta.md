# OAR2 - Field Optics Nonverbal State Expression v1

## OBSERVED

Runtime Lens Interaction + Selective Emphasis is live and verified.

Current standing includes:

- runtime lens convergence
- selectable relation bodies
- emphasis modes
- inspection overlays
- lineage trace visibility
- validation spine behavior
- optics grammar registry
- glyph operator registry
- optics surface registry

The runtime is now interaction-capable without mutating truth.

However:

the optics layer still carries residual explanatory language inside the runtime field itself.

Observed drift conditions:

- labels remain embedded inside optics regions
- textual metrics still compete with perception
- some state explanation remains primary rather than secondary
- dashboard semantics remain partially visible inside the lens instrument

This weakens perceptual compression.

The Field is now structurally capable of expressing more state through:
- geometry
- material
- relation
- glyph
- topology
- motion
- density
- fracture
- convergence
- inscription weight

instead of explanatory text.

## ALIGNED

The next threshold is:

Field Optics Nonverbal State Expression

The optics layer becomes:

nonverbal perceptual governance surface

Words do not disappear from the runtime.

Words move into:

secondary inspection surfaces

The runtime lens itself must express state through:

- geometry
- material behavior
- relation vectors
- glyph standing
- topology
- fracture
- convergence
- motion restraint
- inscription density
- continuity patterns

The lens should become:
- recognizable before readable
- navigable before explainable
- relational before textual

## ROUTED

### 1. Remove explanatory text from optics field

The runtime lens itself may no longer use:
- explanatory labels
- dashboard metrics
- descriptive status text
- repeated state wording

inside the optics surface.

Text may remain:
- outside the lens
- inside inspection overlays
- inside lineage inspection
- inside evidence surfaces

### 2. Preserve optics-only expression rules

Field Optics may express standing only through:

- geometry
- material
- relation
- glyph
- topology
- motion
- density
- fracture
- convergence
- inscription weight

If a state cannot yet be expressed through registered optics behavior, it is not ready for direct lens display.

### 3. Strengthen material semantics

State visibility should increasingly resolve through material behavior:

Crystal:
- coherence
- authority
- active standing
- amplification
- convergence

Obsidian:
- threshold
- blocked standing
- unresolved correction
- fracture
- refusal

Lapis:
- relation
- routing
- adjacency
- continuity
- transition

Marble:
- inscription
- evidence
- sediment
- witnessed continuity
- closure

### 4. Increase glyph compression

Glyph operators should increasingly replace:
- repetitive wording
- status chips
- labels
- explanatory badges

Glyphs must remain:
- registered
- bounded
- relation-derived
- non-decorative

### 5. Increase topology readability

The runtime hierarchy should become understandable through:
- position
- density
- convergence
- orbit
- interruption
- continuity
- spacing
- field tension

without requiring text-first reading.

### 6. Preserve inspection distinction

Inspection overlays remain textual.

Inspection overlays may contain:
- OAR lineage
- evidence
- timestamps
- transition continuity
- validation explanation
- execution standing
- correction detail

The distinction must remain:

optics = perception
inspection = explanation

### 7. Preserve runtime truth boundary

This OAR2 does not authorize:

- simulated standing
- decorative glyph invention
- fake coherence motion
- frontend-authored authority
- hidden blocked states
- autonomous runtime mutation

All optics remain:

read_only_derived_runtime

## CODY ROLE

Cody may:

- reduce explanatory lens text
- strengthen optics-driven state expression
- preserve inspection overlays
- increase glyph compression
- strengthen topology readability
- preserve all registry bindings
- preserve runtime continuity
- preserve accessibility where possible through secondary inspection surfaces

Cody may not:

- remove inspection access
- invent non-registered glyph semantics
- simulate state through fake motion
- flatten authority hierarchy
- bypass optics registries
- hide runtime truth
- collapse optics and inspection into one surface again

## VALIDATION

This OAR2 resolves successfully when:

- optics surfaces become primarily nonverbal
- state is increasingly perceptible before readable
- inspection overlays remain available
- explanatory text recedes from the lens itself
- glyph compression improves
- topology readability strengthens
- material semantics carry more standing
- runtime truth remains preserved
- no mutation or automation is introduced
