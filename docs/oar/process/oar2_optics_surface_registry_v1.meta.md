## ALIGNED

The next threshold is:

Optics Surface Registry

This registry does not define:
- raw runtime state
- component styling
- frontend preference

It defines:

registered perceptual surfaces

- runtime state

become encounterable.

Frontend should assemble optics from seated perceptual contracts rather than manually composing coherence.
