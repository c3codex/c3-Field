# OAR2 - Restore Field Optics Visibility Boundary v1

## OBSERVED

The Field Optics Nonverbal State Expression pass executed, but produced an over-compression failure.

The intended correction was:

optics = perception
inspection = explanation

However, implementation drifted toward:

nonverbal = hidden / collapsed / overly reduced

Observed failure:

- lens optics became visually absent or materially weakened
- process nodes were compressed too far
- geometry lost perceptual readability
- relation lines / topology no longer carried enough visible structure
- state expression collapsed into bars or marks without sufficient field presence
- explanatory text was reduced, but optics were reduced with it

This violates the intended distinction.

Nonverbal optics must remain visible.

Words may recede.

The Field may not disappear.

## ALIGNED

Nonverbal state expression means:

state is expressed without explanatory words

It does NOT mean:

state becomes invisible

The runtime lens must preserve visible expression through:

- geometry
- material
- relation
- glyph
- topology
- fracture
- convergence
- inscription
- density
- motion restraint

The correction must restore the optics visibility boundary.

Text belongs to inspection.

Optics belongs to perception.

The optics layer must remain visually present, legible, and relationally expressive.

## ROUTED

### 1. Restore visible lens geometry

Restore or preserve visible:

- field lens topology
- center authority geometry
- relation rings
- node constellation
- vector paths
- fracture marks
- inscription bands
- glyph operators
- material gradients

Do not collapse the lens into minimal bars or hidden marks.

### 2. Reverse over-aggressive CSS hiding

Review and correct CSS rules from the nonverbal pass that hide too much visual structure.

Specifically inspect rules affecting:

- .c3-lapis-node
- .c3-lapis-node span
- .c3-lapis-state-readout
- .c3-lapis-field
- .c3-lapis-vector
- inscription rail classes
- validation spine classes
- runtime lens overlays

Words may be visually suppressed inside the lens.

Structural optics may not be suppressed.

### 3. Preserve nonverbal rule correctly

The lens may remove or reduce:

- explanatory labels
- repeated metric text
- dashboard wording
- visible process keys as primary display
- status prose

But the lens must retain visible:

- glyphs
- material standing
- node position
- relation topology
- density expression
- fracture visibility
- closure/inscription marks

### 4. Restore process nodes as visible relation bodies

Process nodes should remain:

- visible
- selectable
- focusable
- materially distinct
- topology-positioned
- glyph-supported

They should not become invisible dots without enough semantic material expression.

Inspection overlay may carry text detail.

Node body carries perceptual standing.

### 5. Restore relation topology

Relation must remain visible through:

- arcs
- vectors
- orbit paths
- dependency traces
- blocked-return paths
- correction paths
- lineage traces

Relation topology is not optional.

It is the Field Optics substrate.

### 6. Restore material readability

Material behavior must remain visible:

Crystal:
- center authority
- coherence source
- convergence presence

Obsidian:
- blocked standing
- threshold fracture
- correction pressure

Lapis:
- relation routing
- continuity
- vector standing

Marble:
- inscription
- evidence sediment
- closure trace

Do not reduce materials to color-only micro-marks.

### 7. Preserve inspection surfaces

Inspection overlays remain textual and may include:

- process key
- standing
- OAR2
- expected OAR1
- actual OAR1
- evidence
- correction path
- validation standing
- transition count

This preserves accessibility and operational clarity.

### 8. Add visual failure guard

Add a local visual guard in implementation notes or marker checks:

nonverbal optics must remain visibly present

Validation should confirm:

- lens geometry visible
- process nodes visible
- vectors visible
- glyphs visible
- material standing visible
- inspection text still available

## CODY ROLE

Cody may:

- restore suppressed optics
- revise CSS visibility rules
- preserve nonverbal lens principle correctly
- keep explanatory text in inspection
- restore relation topology
- restore node visibility
- restore material readability
- preserve runtime bindings and registries

Cody may not:

- reintroduce dashboard text into the lens as primary state
- collapse optics into invisible glyph-only marks
- hide relation topology
- remove inspection access
- invent runtime standing
- bypass optics/glyph/surface registries
- mutate runtime state

## VALIDATION

This OAR2 resolves successfully when:

- field optics are visible again
- nonverbal expression remains intact
- explanatory words stay secondary
- lens geometry is restored
- process nodes are visible and selectable
- relation topology is visible
- material semantics are readable
- glyphs support perception without replacing the whole field
- inspection surfaces remain available
- no mutation or automation is introduced
