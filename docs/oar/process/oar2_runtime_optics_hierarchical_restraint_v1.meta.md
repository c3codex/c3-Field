# OAR2 - Runtime Optics Hierarchical Restraint v1

## OBSERVED

The Field Optics runtime has successfully evolved from:
- static dashboard rendering
- textual process exposure
- early relation mapping
- over-compressed nonverbal reduction

into an active perceptual runtime.

The latest correction restored:
- visible topology
- node bodies
- relation paths
- material standing
- glyph presence
- density fields
- inspection separation

However:

the optics layer is now over-speaking.

Observed drift:

- too many simultaneous visual voices
- halos competing with topology
- nodes competing with center authority
- density fields flattening hierarchy
- side rails competing with field gravity
- fracture states visually overweighted
- equal emphasis across unrelated standing

The result is:

field richness without perceptual hierarchy

The runtime now requires:

hierarchical restraint

not additional visual complexity.

## ALIGNED

The runtime lens is not:
- a dashboard
- a metrics console
- an equal-weight graph
- decorative sci-fi UI

The runtime lens is:

a governed perceptual field

Perception must resolve in sequence.

The field should be understood before it is read.

The eye must naturally perceive:

1. center authority
2. relation topology
3. active standing
4. interruption/fracture
5. latent context
6. inspection detail

in descending perceptual priority.

The strongest visual truth:

the center holds gravity

Everything else orbits.

## ROUTED

### 1. Establish perceptual hierarchy order

Runtime optics must visually resolve in this order:

center authority
? relation topology
? active nodes
? state standing
? inscription continuity
? latent context
? inspection detail

Lower-order surfaces must not compete with higher-order surfaces.

### 2. Reduce competing halo intensity

Reduce:
- node glow overlap
- ambient radial bloom
- multi-ring duplication
- equal-weight node halos
- simultaneous pulse behavior

Halos should:
- support standing
- not dominate structure

Only:
- selected
- blocked
- correction
- center-authority

states may carry stronger field pressure.

### 3. Make relation topology primary

Relation lines become:

primary structure carriers

Vectors/arcs/orbits should:
- guide perception
- define movement
- imply dependency
- establish continuity
- reveal interruption

Lines speak before nodes.

Topology speaks before labels.

### 4. Reduce simultaneous node emphasis

Not all nodes should speak equally.

Runtime hierarchy should establish:
- active foreground nodes
- midground continuity nodes
- latent background nodes

Latent nodes should:
- recede
- soften
- remain available
- not disappear entirely

### 5. Restore center gravity dominance

The center field must:
- anchor perception first
- remain calmest
- brightest
- most stable
- least noisy

The center should not compete through complexity.

It should dominate through:
- coherence
- stillness
- inevitability

### 6. Suppress decorative density accumulation

Reduce:
- unnecessary rings
- repeated gradients
- duplicate overlays
- stacked ornamental topology
- decorative signal clutter

If a visual layer does not:
- express standing
- reveal relation
- preserve continuity
- expose interruption

then it should weaken or recede.

### 7. Preserve material semantics

Materials remain distinct:

Crystal:
- coherence
- authority
- convergence
- stillness

Lapis:
- relation
- continuity
- routing
- motion

Obsidian:
- fracture
- refusal
- correction
- threshold pressure

Marble:
- inscription
- evidence
- witnessed continuity
- closure

Materials must remain:
- restrained
- readable
- non-decorative

### 8. Establish latent context posture

Context should remain:

latent until activated

Inspection detail:
- appears on focus
- appears on interaction
- appears on relation selection

The idle field should:
- breathe
- hold structure
- avoid ambient noise

### 9. Preserve inspection distinction

Inspection overlays may remain textual.

The runtime field itself must increasingly express through:
- geometry
- topology
- glyph
- material
- motion
- restraint
- relation gravity

### 10. Add restraint validation pass

Validation must confirm:

- center authority visually dominates
- topology resolves before labels
- nodes do not compete equally
- blocked states do not overpower the field
- latent context remains subdued
- decorative clutter reduced
- inspection remains available
- field feels coherent at distance
- runtime remains registry-derived

## CODY ROLE

Cody may:
- reduce competing visual layers
- rebalance hierarchy
- strengthen topology readability
- soften latent context
- reduce halo noise
- restore center gravity
- preserve runtime truth bindings
- preserve interaction inspection overlays

Cody may not:
- flatten hierarchy
- equalize all nodes visually
- reintroduce dashboard-first UI
- remove relation topology
- hide blocked standing
- invent decorative glyph semantics
- mutate runtime truth
- bypass optics registries

## VALIDATION

This OAR2 resolves successfully when:

- center authority dominates naturally
- relation topology guides perception first
- nodes support rather than compete
- latent context recedes properly
- fracture remains visible without overwhelming
- optics feel gravitational rather than diagrammatic
- inspection detail remains accessible
- the field feels coherent before readable
- runtime truth remains preserved
