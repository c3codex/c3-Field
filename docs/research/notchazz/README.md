# NotChazz Historical Research Custody

Standing: research and historical-evidence custody only. Nothing in this subtree is registered, activated, production-authoritative, or permission-bearing.

## Structure

- `formation/` — research package documents created 2026-08-23.
- `custody/` — source identity, hash standing, lineage and mirror-custody records.
- `incidents/` — matched historical incident bundles and exact-source references.
- `normalized/` — attributed evidence derivatives formed from verified incident bundles.

## Preservation rule

Historical sources remain unchanged. Exact source terminology, identity, custody, dates, standing and lineage are preserved. Normalization occurs only in separately named derivative evidence files with explicit upstream source relations.

A search hit, filename match, later implementation, or file presence does not establish current authority or prove a NotChazz incident.

## Ownership boundary

Current research formation: c3Ops owns the NotChazz service and operational lifecycle. Measures Registry is a governed caller and evidence consumer. Historical sources that use earlier ownership language remain preserved as historical evidence and are not rewritten.

## Hash boundary

Source SHA-256 is recorded only when exact source bytes are available. A hash of a repository derivative or mirrored transcription must never be substituted for the historical source hash.
