# Campaign Replacement Rule

An approved replacement campaign may supersede a prior distribution package while preserving publication history and external evidence.

Required before replacement:
- governed source dispatch remains authoritative;
- replacement package has explicit version and approval standing;
- prior scheduler/post identifiers are preserved as trace;
- no platform state is inferred;
- no automatic submission occurs without a separate OAR2 and operator approval.
