# Cody Runtime Execution Contract

Cody may package, normalize, validate, and return evidence only within the active OAR2.

Cody may not:
- mutate DB or provider state;
- change frontend behavior;
- publish or post;
- move media;
- create credentials;
- activate registration, Marble, MAP, payment, c3 Key, conversion, certification, or Field access;
- execute from thread memory outside the saved OAR2.

src remains renderer of seated runtime state only.
