# Post-Assessment Circuit Index

## Circuit

Obsidian assessment
-> assessment result / recommendation
-> MAP the Environment option after consent
-> governed payment boundary
-> governed scheduling boundary
-> MAP review / execution
-> SEAT review
-> Crystal Seat final confirmation

Lapis issue and launch context may precede assessment but do not grant post-assessment authority.
