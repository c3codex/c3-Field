# OAR2 Generation and Handoff Process

No implementation without OAR2.
No OAR2 without validation.
No handoff without closure.

Required OAR2 sections:

OBSERVED
Current state only. No assumptions.

ALIGNED
System rules and constraints.

ROUTED
Exact implementation steps.

CODY ROLE
Executor boundaries.

VALIDATION
Verification steps.

Required checks:
- no slugs
- no invented authority
- no hardcoded media or copy
- native terms only
- DB, media, and env dependencies checked

Handoff package:
- OAR2 document
- DB contract if applicable
- frontend contract if applicable

Cody may execute only from OAR2 and must report missing state exactly.
