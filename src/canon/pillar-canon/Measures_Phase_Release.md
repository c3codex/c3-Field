# Measures Phase Release Calendar

---

## Spring Equinox — March 20, 2026

**Launch: The Priceless Gallery**

Not the full Measures. Not full revelation. Just the Gallery itself.

The Gallery is Circuit 1 → Connect. Equinox is balance. Light equals dark. Encounter without coercion.

**On this day:**
- Priceless Gallery goes live publicly
- Gate Index visible (all 7 named)
- Marble Index visible (all 13 named)
- Only Gate 0 and Gate 1 accessible
- Crystal Epithets invisible / unnamed
- Marble I seated

This creates architectural intrigue. The structure exists. The system is clearly intentional. But embodiment is withheld.

---

## Gate Descent Sequence — New Moon Cadence

Continue using New Moons for Gate releases.

**Each New Moon:**
- One Gate opens
- Obsidian Scroll visible
- Index already shows its place
- No epithet yet

The audience sees descent unfold deliberately.

This preserves descent as real passage.

---

## Epithet Waves — 3–3–3 on Full Moons

Once Gate 3 or 4 opens, the embodiment rhythm begins.

Crystal Epithets are not named until release. That is the power.

**Each selected Full Moon:**

| Wave | Epithets | Note |
|---|---|---|
| Wave I | Epithets 1–3 revealed and named | Something survived the descent |
| Wave II | Epithets 4–6 revealed and named | The living return |
| Wave III | Epithets 7–9 revealed and named | Embodiment complete |

Epithets embody. They don't govern yet. They are the living return.

## Marble — Seasonal Anchors

Marble is governance. Marble is index-level clarity. Marble is public structure.

Since the Marble Index is already named and stated: you do not release Marble. You seat Marble.

| Marker | Action |
|---|---|
| Spring Equinox (March 20) | Gallery Launch + Marble I seated |
| Summer Solstice | Marble II–IV seated |
| Autumn Equinox | Marble V–IX seated |
| Winter Solstice | Marble X–XIII seated |

Marble becomes the visible spine throughout the year. It signals: integration is stable even while descent continues.
