# CoherentAI System Kernel Index

## Purpose

This index provides the front-door map for the CoherentAI kernel document set stored in `codex-vault/system-kernel/`.

The kernel is the bounded operational structure through which CoherentAI supports the c3 environment in relation to canon, DAO governance, and live pillar activity.

It is not governance.  
It is not a pillar.  
It is the minimal operational system that preserves coherence through:
- bounded roles
- verification
- OAR traceability
- legible results
- structural guardrails

## Governing Principle

The kernel does not create canon.  
The kernel does not become governance.  
The kernel does not replace human authority.

It exists to support bounded, traceable, and coherent operation within the governed foundation of the c3 environment.
