# OAR Formatting Standard

## Purpose

Define the **non-negotiable structure** for OAR records.

OAR is the institutional trace layer.

It must remain:

- verifiable
- non-interpretive
- append-only
- system-valid

OAR does not express meaning.  
OAR records execution.

---

## OAR Types

### OAR1 — Intake (c1)

Records:

- Objective  
- Action  
- Result  

Establishes intake standing.

Does not seat truth.

---

### OAR2 — Return Trace (c3)

Records:

- Observed  
- Aligned  
- Routed  

Verifies post-passage continuity.

---

### OAR Session

Records execution across a defined session.

Uses:

- Observed  
- Action  
- Result  
- Status
