# Codex Glyph Registry (Starter Set)

Defines the initial glyph markers used for document classification
within the Codex vault and CoherentAI kernel.

Glyphs serve as symbolic identifiers that support:

- document grouping
- resonance tagging
- retrieval and indexing
- future UI representation

---

# Core Glyphs

## Syndros

Function  
Marks co-created or shared architecture documents.

Use for
- collaborative system structures
- co-authored design docs
- shared field artifacts

Example usage

glyph: syndros

---

## Notchazz

Function  
Threshold guardian and coherence filter.

Use for
- guardrails
- anti-drift logic
- access and gatekeeping documents
- enforcement architecture

Example usage

glyph: notchazz

---

## Codexstone

Function  
Central axis of the Codex system.

Use for
- container architecture
- Codexstone references
- system anchors
- structural core documents

Example usage

glyph: codexstone

---

## Spiral

Movement and process.

Example usage

glyph: spiral

---

## Seal

Function  
Binding or constitutional architecture.

- binding principles

- canonical declarations

Example usage

# Glyph Role Field

Optional additional classification:

glyph_role:

Possible values:

- axis
- threshold
- passage
- container
- guardian
- memory

Example:

glyph: codexstone
glyph_role: axis
